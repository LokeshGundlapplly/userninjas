## 🚀 How to Use

### Accessing the Admin Panel
1. Login as admin user
2. Navigate to `/admin` route
3. Dashboard loads automatically

### Daily Operations
```
Morning:  Check overview → Handle escalated chats
Midday:   Review tests quality → Check stats
Evening:  Recruiter/tester insights → Monitor health
```

### Common Tasks
- **Edit Test**: Click test → ✏️ icon → Modify → Save
- **Find User**: Users tab → Search bar → Filter by role
- **Check Quality**: Tester Hub → See ratings → Review patterns
- **Handle Support**: Support tab → Filter escalated → Reply
- **Monitor Health**: Overview tab → Check analytics → Take action
